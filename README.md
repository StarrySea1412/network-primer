# 你按下回车之后 · 网络科普手册

> 一个网页从域名到眼前的四百毫秒旅行——DNS 解析、TCP 握手、分层封装、HTTP 往返、路由跳数，五段确定性互动，每一跳都能亲手发车。

**在线阅读：<https://starrysea1412.github.io/network-primer/>**

## 五段互动（全程确定性模拟）

1. **DNS 解析台** —— 八步问路动画：电脑 → 递归解析器 → 根 → TLD → 权威，真实量级延迟；清空缓存对比二次查询的缓存命中
2. **TCP 连接台** —— 三次握手逐步发车（seq/ack 真实递增），数据段可注入丢包，看超时重传与重复报文丢弃
3. **封装台** —— 四层信封（TCP/IP/以太网）逐层套上与拆下，左右双画布同步，每层说明「管什么」
4. **HTTP 往返台** —— 切换 200/301/404/500/304 状态码，看服务器的应答与浏览器的连锁反应（301 = 额外一次完整往返）
5. **路由追踪台** —— TTL 逐次 +1 走完七跳拓扑，RTT 逐跳累计并定位「跨洋跳变」（+124ms 谁也优化不掉）
